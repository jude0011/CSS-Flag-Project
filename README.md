# CSS-Flag-Project

This project is a collection of national flags created purely with **HTML and CSS**.
The goal of the project is to demonstrate how different flag designs can be recreated using CSS properties such as **flexbox, positioning, gradients, and shapes**.

## 📌 Project Overview

Flags are built using simple HTML elements styled with CSS to represent the colors, patterns, and shapes of real-world country flags. This project helps improve CSS layout skills and understanding of positioning techniques.

## 🚀 Features

* Pure **HTML & CSS implementation**
* No images used
* Responsive layout
* Clean and simple code structure
* Easy to add more flags

## 🛠 Technologies Used

* **HTML5**
* **CSS3**
* Flexbox
* CSS Positioning
* CSS Shapes
